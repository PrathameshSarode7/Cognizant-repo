--ElastiCache Overview
 Simple Idea
 ElastiCache = In-memory cache
 Stores data in RAM → super fast

Use cache when:
✅ Same data requested frequently
✅ Reduce DB load
✅ Improve app speed
eg-:
Redis
Memcached
