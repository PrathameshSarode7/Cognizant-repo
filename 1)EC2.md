\--Spot Instance

AWS has extra unused servers in its data centers.

Instead of keeping them idle, AWS sells them very cheap.

That cheap EC2 = Spot Instance



AWS can take back the instance anytime if:

Demand increases

Someone pays higher price

Capacity is needed

aws give 2min warning before terminating the spot instance



reserve instance is expensive but safe than spot instance
