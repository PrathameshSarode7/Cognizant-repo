Zomato hires more delivery boys during rush

--Scaling Policies

1. Target Tracking (MOST IMPORTANT)
 Keep metric at fixed value
Example:

CPU = 50%

If CPU > 50% → add instance
If CPU < 50% → remove instance
 Easiest & most used

2. Step Scaling
 Scale based on thresholds
Example:

CPU > 70% → +1 instance
CPU > 90% → +2 instances


3. Scheduled Scaling
 Scale at specific time
Example:

Add instances at 9 AM (office hours)
